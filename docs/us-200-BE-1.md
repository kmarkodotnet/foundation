## Story

> As a **PlatformAdmin**, I want to create a new Owner and send an initial OwnerAdmin invitation, so that a new client can start using the system.

---

## Scope

Megvalósítja az `Owner.Create()` domain logikát, a `ProvisionOwnerCommand` handlert, az Owner alapértelmezett kódszótár-sablon örökítését és az OwnerAdmin meghívó kiküldését. Tartalmazza az Owner listázó és részletes lekérdező végpontot is.

## API Contract

### POST /api/v1/platform/owners
**Auth:** `IsPlatformAdmin`

**Request:**
```json
{
  "name": "Béta Alapítványkezelő Kft.",
  "contactEmail": "tech@betakft.hu",
  "initialOwnerAdminEmail": "admin@betakft.hu"
}
```

**Response 201:**
```json
{ "id": "...", "name": "Béta Alapítványkezelő Kft.", "status": "Active" }
```

**400** — Validációs hiba (üres mező, invalid email)  
**409** — `initialOwnerAdminEmail` már foglalt más Owner-nél

### GET /api/v1/platform/owners

| Query param | Típus | Leírás |
|---|---|---|
| `status` | `string?` | Active/Suspended/Archived szűrő |
| `page` | `int` | 1-től indexelt |
| `pageSize` | `int` | Max 100 |

## FluentValidation Rules

| Field | Rule | Error |
|---|---|---|
| `Name` | `NotEmpty().MaximumLength(200)` | "Az Owner neve kötelező." |
| `ContactEmail` | `NotEmpty().EmailAddress()` | "Érvényes kapcsolattartó e-mail szükséges." |
| `InitialOwnerAdminEmail` | `NotEmpty().EmailAddress()` | "Érvényes OwnerAdmin e-mail szükséges." |
| `InitialOwnerAdminEmail` | Custom: `DbContext.AppUsers.None(u => u.Email == x && u.OwnerId != null)` | "Ez az e-mail cím már egy másik Owner-hez tartozik." |
