## Story

> As a **PlatformAdmin**, I want to create a new Owner and send an initial OwnerAdmin invitation through the UI, so that I can onboard a new client.

---

## Scope

A `/platform/owners` lista oldal és az Owner létrehozási form megvalósítása. A form a `POST /api/v1/platform/owners` végpontot hívja. Az Owner részletező oldal alap megjelenítése is itt valósul meg.

## UX / Behaviour

| Scenario | Expected behaviour |
|---|---|
| Sikeres Owner létrehozás | Snackbar: „Owner sikeresen létrehozva." + dialog bezár + lista frissül |
| 409 (foglalt e-mail) | `initialOwnerAdminEmail` mező piros, hibaüzenet: „Ez az e-mail cím már egy másik Owner-hez tartozik." |
| PlatformAuditor megnyitja | „Új Owner" gomb rejtett; csak lista és részletek látszik |
| Lista üres | Empty state: „Még nincs egyetlen Owner sem. Hozz létre egyet." |
