## Scope

Platform-szintű meghívó kiállítása (`Scope = PLATFORM`, `Role = PlatformAdmin | PlatformAuditor`). A meghívó elfogadásakor az `AppUser` kap `PlatformRole`-t, és `OwnerId` null marad. Az utolsó admin szabály és az öndemotiváció tilalma is érvényesül.

## API Contract

### POST /api/v1/platform/users/invite
**Auth:** `IsPlatformAdmin`

**Request:**
```json
{ "email": "auditor@platform.hu", "role": "PlatformAuditor" }
```

**201:** Meghívó kiküldve  
**400:** Érvénytelen email vagy szerepkör  
**409:** E-mail már Owner/Foundation scope-hoz tartozik
