## Scope

A `/platform/users` lista és az „Új meghívó" dialog megvalósítása platform-scope-ra.

---

## Acceptance Criteria

- [ ] **AC1**: A `/platform/users` oldalon megjelenik a platform-scope-ú felhasználók listája és az „Új meghívó" funkció. PlatformAuditor-nál az „Új meghívó" gomb rejtett (`*hasRole="['PlatformAdmin']"`).
- [ ] **AC2**: A meghívó form mezői: e-mail cím (érvényes formátum), szerepkör (MatSelect: `PlatformAdmin` / `PlatformAuditor`). A meghívó hatóköre automatikusan `PLATFORM` (a UI ezt explicit jelzi: olvasható badge „Hatókör: Platform" a dialog tetején).
- [ ] **AC3**: A meghívási folyamat egyébként megegyezik US-164-gyel (lásd `CR1_us-164-FE-1.md`): sikeres küldés → snackbar, 409 PENDING → másodlagos dialog újraküldés felajánlással, validációs hibák mezőnként.
- [ ] **AC4**: A meghívott felhasználó **nem rendelkezhet egyszerre** Owner/Foundation-szintű szerepkörrel — a backend validáció erre 422-vel jelez (NK-13 sérülés). A UI a hibaüzenetet field-level hibajelzéssel mutatja: „Ez az e-mail cím már egy Owner-hez/Foundation-hoz tartozik. Platform-szintű meghívó nem küldhető."
- [ ] **AC5**: Utolsó admin szabály érvényesül a felhasználói listán: az utolsó aktív PlatformAdmin sorában a „Szerepkör módosítása" → `PlatformAuditor` opció disabled tooltipi-vel: „Az utolsó PlatformAdmin szerepköre nem vonható vissza." A saját felhasználó sorában minden szerepkör-módosító és inaktiváló gomb rejtett (self-demotion ban).
