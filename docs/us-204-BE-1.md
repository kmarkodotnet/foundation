## Scope

Platform-szintű konfigurációs értékek (fájlméret-korlát, meghívó érvényességi idő, értesítési határidők, default kódszótár-sablon azonosítója) olvasása és frissítése. Az értékek egy `PlatformSettings` táblában tárolódnak (singleton sor).

## API Contract

### PATCH /api/v1/platform/settings
**Auth:** `IsPlatformAdmin`

**Request:**
```json
{
  "maxFileSizeMb": 100,
  "invitationExpiryHours": 48
}
```

**200:** frissített `PlatformSettingsResponse`  
**400** — Érvénytelen értékek (pl. MaxFileSizeMb < 1)
