## Scope

Platform-szintű audit napló végpont: az összes Owner és platform-szintű esemény szűrt, lapozható lekérdezése. `IgnoreQueryFilters()` (whitelisted callsite) a tenant-scope filter megkerülésével. CSV export.

---

## Implementation Checklist

### Application Layer (`GrantManagement.Application`)
- [ ] `GetPlatformAuditLogsQuery`: `Application/Platform/AuditLogs/Queries/GetPlatformAuditLogs/`
  - Szűrő paraméterek: `UserId?`, `OwnerId?`, `StartDate?`, `EndDate?`, `Action?`
  - `[ScopeBypassAllowed("Platform-level audit log requires cross-owner access")]` a lekérdezésen
- [ ] `GetPlatformAuditLogsQueryHandler`: `IgnoreQueryFilters()` az `AuditLogs` DbSet-en; a többi business entitáson nem
- [ ] `ExportPlatformAuditLogsCsvCommand` + Handler

### API Layer (`GrantManagement.API`)
- [ ] `PlatformAuditLogsController`: `API/Controllers/Platform/PlatformAuditLogsController.cs`
  - `GET /api/v1/platform/audit-logs` — `[Authorize(Policy = "CanReadPlatform")]`
  - `GET /api/v1/platform/audit-logs/export` — `[Authorize(Policy = "CanReadPlatform")]`
  - **NINCS `[HttpDelete]` action** (AC5) — a controller explicit dokumentált hiányként kezeli a törlési endpoint hiányát.

### Törlés-tilalom architektúrális megvalósítás (AC5)
- [ ] `AppDbContext.SaveChangesAsync` override-ban: `ChangeTracker.Entries<AuditLog>().Any(e => e.State == EntityState.Deleted)` esetén `InvalidOperationException("AuditLog rekordok nem törölhetők.")` — minden szinten (platform/owner/foundation napló egyaránt).
- [ ] NetArchTest szabály: `AuditLog` típusra nem hivatkozik `Remove()` vagy `RemoveRange()` az egész codebase-en kívül a `AuditLogRetentionJob` archiválási tranzakciója.
- [ ] Integration teszt: `DELETE /api/v1/platform/audit-logs/{id}` → 404 (endpoint nem létezik); `DELETE /api/v1/owner/audit-logs/{id}` → 404; `DELETE /api/v1/audit-logs/{id}` → 404.

## API Contract

### GET /api/v1/platform/audit-logs

| Param | Leírás |
|---|---|
| `ownerId` | Owner szűrő |
| `userId` | PlatformAdmin szűrő |
| `action` | pl. OWNER_PROVISIONED, BREAK_GLASS_ACCESS |
| `page`, `pageSize` | Lapozás |

**Response:** AuditLogListResponse (BREAK_GLASS_ACCESS sorok `isBreakGlass: true`-val)
