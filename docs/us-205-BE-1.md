## Scope

Platform-szintű audit napló végpont: az összes Owner és platform-szintű esemény szűrt, lapozható lekérdezése. `IgnoreQueryFilters()` (whitelisted callsite) a tenant-scope filter megkerülésével. CSV export.

## API Contract

### GET /api/v1/platform/audit-logs

| Param | Leírás |
|---|---|
| `ownerId` | Owner szűrő |
| `userId` | PlatformAdmin szűrő |
| `action` | pl. OWNER_PROVISIONED, BREAK_GLASS_ACCESS |
| `page`, `pageSize` | Lapozás |

**Response:** AuditLogListResponse (BREAK_GLASS_ACCESS sorok `isBreakGlass: true`-val)
