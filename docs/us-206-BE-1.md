## Story

> As a **PlatformAdmin**, I want to issue temporary Owner-level access to a specific Owner's data with justification, so that I can assist in a technical emergency or regulatory data request.

---

## Scope

`BreakGlassGrant.Issue()` domain logika, a kiállítási command handler, az OwnerAdmin értesítés és az új break-glass JWT kiállítás. A `CurrentScopeService.CanAccessOwner()` break-glass ág szintén itt kerül integrációra.

---

## Implementation Checklist

### Application Layer (`GrantManagement.Application`)
- [ ] `IssueBreakGlassGrantCommand`: `Application/Platform/BreakGlass/Commands/IssueBreakGlass/` — `TargetOwnerId: Guid`, `Reason: string`
- [ ] `IssueBreakGlassGrantCommandHandler`:
  1. Ellenőrzi: Owner létezik, `Status != ARCHIVED`
  2. `BreakGlassGrant.Issue(platformAdminUserId, targetOwnerId, reason)` — `ExpiresAt = now + 24h`
  3. `BreakGlassActivated` domain esemény → `BreakGlassNotificationHandler` → email az OwnerAdmin-nak
  4. Új JWT kiállítása a PlatformAdmin-nak: `audience = "owner"` + `break_glass_grant_id` claim (a JwtTokenService.GenerateBreakGlassToken() metódussal)
  5. Audit: `BREAK_GLASS_ACCESS` (PlatformAdmin, TargetOwner, Reason, ExpiresAt)
- [ ] `IssueBreakGlassGrantCommandValidator`: `Reason.MinimumLength(20)`, `TargetOwnerId` NotEmpty
- [ ] `GetBreakGlassGrantsListQuery` + Handler: aktív grant-ek listázása PlatformAdmin-nak
- [ ] `BreakGlassGrantListItemResponse` DTO: `{ Id, TargetOwnerId, TargetOwnerName, IssuedAt, ExpiresAt, Status }`
- [ ] `BreakGlassGrantIssueResponse` DTO: `{ GrantId, AccessToken, ExpiresAt }`

### Domain Layer (`GrantManagement.Domain`)
- [ ] `BreakGlassGrant.Issue()` statikus factory: validálja `Reason.Length >= 20`, `ExpiresAt > IssuedAt`; kiváltja `BreakGlassActivated`
- [ ] `BreakGlassNotificationHandler` (domain event handler): kiviszi az `OwnerAdmin` email értesítést

### Infrastructure Layer (`GrantManagement.Infrastructure`)
- [ ] `JwtTokenService.GenerateBreakGlassToken(AppUser platformAdmin, BreakGlassGrant grant)`: audience = `owner` (speciális break-glass context), `owner_id = grant.TargetOwnerId`, `break_glass_grant_id = grant.Id`; 8 óra lejárat (nem 24 óra — a grant lejárata külön ellenőrzött)
- [ ] `CurrentScopeService.CanAccessOwner(ownerId)` break-glass ág véglegesítése: lekérdezi `BreakGlassGrants` ahol `Status == Active && ExpiresAt > now && TargetOwnerId == ownerId && PlatformAdminUserId == currentUser.Id`; ha van ilyen → true + BREAK_GLASS_ACCESS flag az audit-hoz

### API Layer (`GrantManagement.API`)
- [ ] `BreakGlassController`: `API/Controllers/Platform/BreakGlassController.cs`
  - `POST /api/v1/platform/break-glass` — `[Authorize(Policy = "CanIssueBreakGlass")]`
  - `GET /api/v1/platform/break-glass` — `[Authorize(Policy = "CanReadPlatform")]`

## API Contract

### POST /api/v1/platform/break-glass
**Auth:** `CanIssueBreakGlass` (IsPlatformAdmin)

**Request:**
```json
{
  "targetOwnerId": "3fa85f64-...",
  "reason": "Jogszabályi adatkiadás – NAV megkeresés 2025/1234"
}
```

**Response 200:**
```json
{
  "grantId": "...",
  "accessToken": "eyJhbGci...",
  "expiresAt": "2025-06-02T10:00:00Z"
}
```

**400** — Reason < 20 karakter  
**404** — Owner nem létezik  
**422** — Owner ARCHIVED (nem lehet break-glass-t kiállítani)

## FluentValidation Rules

| Field | Rule | Error |
|---|---|---|
| `TargetOwnerId` | `NotEmpty()` | "A célzott Owner azonosítója kötelező." |
| `Reason` | `NotEmpty().MinimumLength(20)` | "Az indoklás legalább 20 karakter legyen." |
