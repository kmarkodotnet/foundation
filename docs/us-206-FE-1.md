## Scope

Az Owner részletező oldalon a „Break-glass hozzáférés" gomb és a megerősítő indoklási modál. A kiállítás után kapott AccessToken-nel a kliens átnavigál az Owner UI-ra.

---

## Implementation Checklist

### Feature Module
- [ ] `break-glass-issue-dialog.component.ts` + `.html`:
  - Textarea: kötelező indoklás, min 20 karakter, karakterszámláló megjelenítve
  - „Megerősítés" gomb disabled, amíg < 20 karakter
  - Figyelmeztető szín + ikon (destructive dialog stílus)
- [ ] `owner-details.component.ts` bővítése: „Break-glass hozzáférés" gomb PlatformAdmin-nak
- [ ] `PlatformBreakGlassService`: `issueGrant(targetOwnerId, reason)` → visszaad `{ grantId, accessToken, expiresAt }`
- [ ] A visszakapott `accessToken`-t a kliens tárolja a localStorage-ban (párhuzamosan a platform token mellett) és a navigáció `/owner/:ownerId` route-ra mutat (az Owner UI break-glass módban nyílik meg)
- [ ] Break-glass módban az Owner UI fejlécén figyelmeztető banner: „Break-glass mód aktív – hozzáférés lejár: {expiresAt}"

### Route
- [ ] `platform/break-glass` — aktív break-glass grant-ek listája (us-207-FE-1-ben)

## API Consumed

| Method | URL | Body | Response |
