## Scope

`BreakGlassGrant.Revoke()` domain logika, manuális visszavonás command és a `BreakGlassExpirationJob` Hangfire recurring job. A lejárt/visszavont grant-hez tartozó JWT-kérések 403-at kapnak.

---

## Implementation Checklist

### Application Layer (`GrantManagement.Application`)
- [ ] `RevokeBreakGlassGrantCommand`: `Application/Platform/BreakGlass/Commands/RevokeBreakGlass/` — `GrantId: Guid`
- [ ] `RevokeBreakGlassGrantCommandHandler`: `BreakGlassGrant.Revoke()`, `RevokedAt = now`, audit `BREAK_GLASS_REVOKED`

### Domain Layer (`GrantManagement.Domain`)
- [ ] `BreakGlassGrant.Revoke()`: csak `ACTIVE` állapotnál; `REVOKED`-ra állítja, `RevokedAt = now`; kiváltja `BreakGlassRevoked` eseményt
- [ ] `BreakGlassGrant.IsValidAt(DateTimeOffset now)`: `Status == ACTIVE && ExpiresAt > now`

### Infrastructure Layer (`GrantManagement.Infrastructure`)
- [ ] `BreakGlassExpirationJob`: `Infrastructure/BackgroundJobs/BreakGlassExpirationJob.cs`
  - Hangfire recurring, óránként (`Cron.Hourly()`)
  - `[ScopeBypassAllowed("Background job — checks all active break-glass grants across owners")]`
  - Lekérdezi az összes ACTIVE grant-et ahol `ExpiresAt < now`
  - Minden grantnél: `grant.Status = EXPIRED`, `IAuditLogger.Log(BREAK_GLASS_EXPIRED, grantId, targetOwnerId)`
  - `_scope.SwitchTo(grant.TargetOwnerId)` minden iteráció előtt (audit helyes OwnerId-vel)
  - Hangfire regisztráció `Program.cs`-ben
- [ ] `ScopeValidationMiddleware` bővítése: Minden kérésnél ha `break_glass_grant_id` claim van a JWT-ben, ellenőrzi a `BreakGlassGrants` táblában `Status == ACTIVE && ExpiresAt > now`; ha nem teljesül → 403 `"Break-glass hozzáférés lejárt vagy visszavonva."`

### API Layer (`GrantManagement.API`)
- [ ] `BreakGlassController` bővítése: `POST /api/v1/platform/break-glass/{id}/revoke` — `[Authorize(Policy = "CanIssueBreakGlass")]`

---

## API Contract

### POST /api/v1/platform/break-glass/{id}/revoke
**Auth:** `CanIssueBreakGlass`  
**Response 200:** `{ "status": "Revoked", "revokedAt": "..." }`  
**400** — Grant nem ACTIVE állapotú  
**404** — Grant nem létezik
