## API Consumed

| Method | URL | Response |
|---|---|---|
| `GET` | `/api/v1/platform/break-glass` | `BreakGlassGrantListItem[]` |
| `POST` | `/api/v1/platform/break-glass/:id/revoke` | `{ status, revokedAt }` |

## UX / Behaviour

| Scenario | Expected behaviour |
|---|---|
| ACTIVE grant | Visszavonás gomb látható |
| REVOKED/EXPIRED grant | Visszavonás gomb nem látható |
| Visszavonás után | Snackbar + lista frissítés (grant státusz REVOKED lesz) |
| Üres lista | Empty state: „Nincs aktív break-glass hozzáférés." |
