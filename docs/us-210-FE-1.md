## Scope

A `/owner/foundations` lista oldal és a Foundation létrehozási form (dialog). Tartalmazza az opcionális logó feltöltést és a template-Foundation-választót.

---

## Implementation Checklist

### Feature Module (`src/app/features/owner/foundations/`)
- [ ] `foundations-list.component.ts` + `.html` — Foundation lista kártyákkal vagy táblával (név, státusz, pályázatok száma), „Új alapítvány" gomb
- [ ] `foundation-create-dialog.component.ts` + `.html`:
  - `name`: kötelező text input
  - `initialFoundationAdminEmail`: kötelező email input
  - `logoUri`: opcionális fájlupload (`<app-file-upload>`)
  - `templateFoundationId`: opcionális MatSelect (Owner saját aktív Foundation-jai közül)
- [ ] `OwnerFoundationService`: `list()`, `create()`, `getById()` metódusok
- [ ] Route-ok: `owner/foundations` (lista), `owner/foundations/:id` (részletek)

### Reactive Form
- [ ] `name`: `[required, maxLength(200)]`
- [ ] `initialFoundationAdminEmail`: `[required, email]`
- [ ] `logoUri`: opcionális, file upload
- [ ] `templateFoundationId`: opcionális MatSelect

### State / Data Flow
- [ ] Sikeres Foundation létrehozás → snackbar „Alapítvány sikeresen létrehozva." + dialog bezár + lista frissítés
- [ ] 422 (Owner nem aktív) → toast: „Az Owner nem aktív állapotban van."

## Acceptance Criteria

- [ ] **AC1**: A `/owner/foundations` oldalon megjelenik a Foundation lista és az „Új alapítvány" gomb. A lista oszlopai: név, státusz badge, aktív pályázatok darabszáma, létrehozás dátuma.
- [ ] **AC2**: A létrehozó form mezői: alapítvány neve (`required, maxLength(200)`), opcionális logó (`accept="image/*"`, max 2 MB, képi dimenzió-validáció ≤ 512×512 px — lásd `architecture-plan.md` CR2.F), kezdő FoundationAdmin Google-fiók email (`required, email`). Submit gomb a form érvényesülésig disabled.
- [ ] **AC3**: A létrehozáskor a backend automatikusan átmásolja az Owner-szintű kódszótár-sablont az új Foundation-be (snapshot, NK-16) — a UI ezt csak visszajelzéssel mutatja: snackbar „Alapítvány létrehozva, kódszótár-sablon átmásolva."
- [ ] **AC4**: A form opcionálisan megengedi egy meglévő saját alapítvány kiválasztását (`templateFoundationId` MatSelect — csak az Owner saját aktív alapítványaival), amelynek Pályáztatóit és Szerződő cégeit a backend átmásolja (NK-15). A select tooltipje: „Az új alapítvány örökli a kiválasztott alapítvány Pályáztatóit és Szerződő cégeit."
- [ ] **AC5**: Sikeres létrehozás után a UI snackbar visszajelzést mutat: „Alapítvány létrehozva. Meghívó e-mail kiküldve: {email}". A megadott Google-fiók a háttérben `FOUNDATION` hatókörű meghívót kap FoundationAdmin szerepkörre (a backend felelőssége).
- [ ] **AC6**: Hibakezelés: 422 (Owner nem aktív, NK-13 sérülés) → snackbar a backend-üzenettel; 400 (validáció) → field-level hibajelzés a form-mezőkön.
