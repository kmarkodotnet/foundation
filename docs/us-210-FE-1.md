## Scope

A `/owner/foundations` lista oldal és a Foundation létrehozási form (dialog). Tartalmazza az opcionális logó feltöltést és a template-Foundation-választót.

---

## Implementation Checklist

### Feature Module (`src/app/features/owner/foundations/`)
- [ ] `foundations-list.component.ts` + `.html` — Foundation lista kártyákkal vagy táblával (név, státusz, pályázatok száma), „Új alapítvány" gomb
- [ ] `foundation-create-dialog.component.ts` + `.html`:
  - `name`: kötelező text input
  - `initialFoundationAdminEmail`: kötelező email input
  - `logoUri`: opcionális fájlupload (`<app-file-upload>`)
  - `templateFoundationId`: opcionális MatSelect (Owner saját aktív Foundation-jai közül)
- [ ] `OwnerFoundationService`: `list()`, `create()`, `getById()` metódusok
- [ ] Route-ok: `owner/foundations` (lista), `owner/foundations/:id` (részletek)

### Reactive Form
- [ ] `name`: `[required, maxLength(200)]`
- [ ] `initialFoundationAdminEmail`: `[required, email]`
- [ ] `logoUri`: opcionális, file upload
- [ ] `templateFoundationId`: opcionális MatSelect

### State / Data Flow
- [ ] Sikeres Foundation létrehozás → snackbar „Alapítvány sikeresen létrehozva." + dialog bezár + lista frissítés
- [ ] 422 (Owner nem aktív) → toast: „Az Owner nem aktív állapotban van."
