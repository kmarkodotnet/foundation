## Scope

`Foundation.Archive()` domain logika (aktív Application-ok ellenőrzése), az OwnerAdmin archiváló command és a Foundation felhasználó-hozzárendelések automatikus inaktiválása.

---

## Implementation Checklist

### Application Layer (`GrantManagement.Application`)
- [ ] `ArchiveFoundationCommand`: `Application/OwnerAdministration/Foundations/Commands/ArchiveFoundation/` — `FoundationId: Guid`
- [ ] `ArchiveFoundationCommandHandler`:
  1. `IApplicationCountService.GetActiveCount(foundationId)` — ha > 0: `DomainException("N aktív pályázat van; először zárd le őket.")`
  2. `Foundation.Archive()` — `FoundationArchived` esemény
  3. `FoundationUserAssignment.IsActive = false` az összes, az adott Foundation-hoz tartozó hozzárendelésre (bulk update)
  4. Audit: `FOUNDATION_ARCHIVED`

### Domain Layer (`GrantManagement.Domain`)
- [ ] `Foundation.Archive()`: csak `ACTIVE` állapotnál; `ARCHIVED`-re állítja; `FoundationArchived` esemény; az Application-ellenőrzést a domain service végzi (`IApplicationCountService`)

### API Layer (`GrantManagement.API`)
- [ ] `FoundationsController` bővítése: `POST /api/v1/owner/foundations/{id}/archive` — `[Authorize(Policy = "IsOwnerAdmin")]`

---

## API Contract

**POST /api/v1/owner/foundations/{id}/archive**  
Auth: `IsOwnerAdmin`  
**200:** `{ "status": "Archived" }`  
**400:** `"3 aktív pályázat van; először zárd le őket."` (aktív Application)  
**403:** Foundation más Owner-é (scope mismatch)  
**404:** Foundation nem létezik
