## Scope

FoundationAdmin szerepkör kiosztása meglévő Owner-felhasználónak meghívó nélkül, vagy új meghívóval. Utolsó admin szabály végrehajtása. OwnerAdmin kettős szerepkörének kezelése.

---

## Implementation Checklist

### Application Layer (`GrantManagement.Application`)
- [ ] `AssignFoundationAdminCommand`: `Application/OwnerAdministration/Foundations/Commands/AssignFoundationAdmin/`
  - `FoundationId: Guid`, `TargetUserId: Guid` (meglévő Owner-user), `Role: FoundationRole`
- [ ] `AssignFoundationAdminCommandHandler`:
  1. Ellenőrzi: `TargetAppUser.OwnerId == currentScope.OwnerId`
  2. `AppUser.AssignToFoundation(foundationId, FoundationAdmin, assignedBy)` — `FoundationAssignmentCreated` esemény
  3. Ha már van aktív hozzárendelés ugyanehhez a Foundation-hoz: `ChangeFoundationRole()` helyett (vagy hiba ha már FoundationAdmin)
  4. Audit: `FoundationAssignmentCreated`
- [ ] `RevokeFoundationAdminCommand` + Handler:
  - Utolsó admin szabály: `IFoundationAdminCountService.GetActiveCount(foundationId) <= 1` → `DomainException("Az utolsó FoundationAdmin szerepköre nem vonható vissza.")`
  - `AppUser.RevokeFoundationAssignment(foundationId)` — IsActive = false
- [ ] `GetFoundationAdminsQuery` + Handler: Foundation-hoz rendelt FoundationAdmin-ok listája
- [ ] `FoundationAdminListItemResponse` DTO: `{ UserId, Email, FullName, AssignedAt }`

### API Layer (`GrantManagement.API`)
- [ ] `FoundationsController` bővítése:
  - `GET /api/v1/owner/foundations/{id}/admins` — `[Authorize(Policy = "CanReadOwner")]`
  - `POST /api/v1/owner/foundations/{id}/admins` — `[Authorize(Policy = "IsOwnerAdmin")]`
  - `DELETE /api/v1/owner/foundations/{id}/admins/{userId}` — `[Authorize(Policy = "IsOwnerAdmin")]`

## API Contract

### POST /api/v1/owner/foundations/{id}/admins
**Auth:** `IsOwnerAdmin`

**Request:**
```json
{ "targetUserId": "...", "role": "FoundationAdmin" }
```

**200:** `{ "assignmentId": "...", "userId": "...", "role": "FoundationAdmin" }`  
**400** — Utolsó FoundationAdmin (revoke esetén)  
**404** — Foundation vagy User nem létezik  
**422** — TargetUser más Owner-hez tartozik
