## Scope

A Foundation részletező oldalon a FoundationAdmin-ok listája és a közvetlen kinevezési / visszavonási funkció.

---

## Implementation Checklist

### Feature Module
- [ ] Foundation részletes nézet bővítése „Adminok" lapfüllel: FoundationAdmin lista (email, AssignedAt) visszavonás gombbal
- [ ] „FoundationAdmin kinevezése" modális dialog: MatSelect (Owner-hez tartozó felhasználók listájából), szerepkör mező
- [ ] Visszavonás: disabled ha csak egy FoundationAdmin van (tooltip: „Az utolsó FoundationAdmin nem vonható vissza.")
- [ ] `OwnerFoundationService.assignAdmin()`, `revokeAdmin()` metódusok

## UX / Behaviour

| Scenario | Expected behaviour |
|---|---|
| Egy FoundationAdmin van | Visszavonás gomb disabled + tooltip |
| Kinevezés sikerült | Snackbar + lista frissítés |
| Visszavonás sikerült | Snackbar + felhasználó eltűnik a listából |
