## Scope

A Foundation részletező oldalon a FoundationAdmin-ok listája és a közvetlen kinevezési / visszavonási funkció.

---

## Acceptance Criteria

- [ ] **AC1**: A `/owner/foundations/{id}/admins` (Foundation részletes → „Adminok" lapfül) listán látszanak az adott alapítvány FoundationAdmin-jai (oszlopok: profilkép, név, email, AssignedAt, visszavonás gomb).
- [ ] **AC2**: Új FoundationAdmin meghívása dialogusban: vagy MatSelect a meglévő Owner-felhasználók közül (akik még nem FoundationAdmin-ok), vagy „Új meghívó" gomb az új email-re. Új meghívó esetén a UI explicit jelzi: „Foundation hatókörű meghívó kerül kiküldésre FoundationAdmin szerepkörrel."
- [ ] **AC3**: Meglévő Owner-felhasználó kiválasztása esetén a kinevezés meghívó nélkül történik (közvetlen `POST /api/v1/owner/foundations/{id}/admins` az `appUserId`-vel). Audit-esemény visszajelzés a snackbar-on: „Felhasználó kinevezve FoundationAdmin szerepkörre."
- [ ] **AC4**: Az utolsó FoundationAdmin visszavonási gombja UI-szinten letiltott; tooltip: „Az utolsó FoundationAdmin nem vonható vissza."
- [ ] **AC5**: OwnerAdmin önmagát is kinevezheti FoundationAdmin-nak az adott alapítványban (NK-17 — a UI ezt nem tiltja, a backend külön audit-bejegyzést készít a kettős kinevezésről). A UI snackbar visszajelzése: „Saját maga FoundationAdmin szerepkörre kinevezve — kettős szerepkör aktív."

---

## Implementation Checklist

### Feature Module
- [ ] Foundation részletes nézet bővítése „Adminok" lapfüllel: FoundationAdmin lista (email, AssignedAt) visszavonás gombbal
- [ ] „FoundationAdmin kinevezése" modális dialog: MatSelect (Owner-hez tartozó felhasználók listájából), szerepkör mező
- [ ] Visszavonás: disabled ha csak egy FoundationAdmin van (tooltip: „Az utolsó FoundationAdmin nem vonható vissza.")
- [ ] `OwnerFoundationService.assignAdmin()`, `revokeAdmin()` metódusok
