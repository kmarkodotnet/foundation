## Scope

Owner-szintű meghívó kiállítása Foundation-szintű hozzárendelések payload-jával. Meghívó elfogadásakor az AppUser `OwnerId`-je beállítódik és az összes Foundation hozzárendelés aktiválódik. Meglévő Owner-user közvetlen Foundation-hozzárendelése meghívó nélkül.

## API Contract

### POST /api/v1/owner/users/invite
**Auth:** `IsOwnerAdmin`

**Request:**
```json
{
  "email": "munkatars@alapitvany.hu",
  "foundationAssignments": [
    { "foundationId": "...", "role": "PalyazatiMunkatars" },
    { "foundationId": "...", "role": "Megtekinto" }
  ]
}
```

**201:** `{ "invitationId": "..." }`  
**400** — Validációs hiba, üres foundationAssignments  
**409** — Email más Owner-hez tartozik (NK-13)

---

## FluentValidation Rules

| Field | Rule | Error |
|---|---|---|
| `Email` | `NotEmpty().EmailAddress()` | "Érvényes e-mail cím szükséges." |
| `FoundationAssignments` | `NotEmpty()` | "Legalább egy Foundation-hozzárendelés kötelező." |
| `FoundationAssignments[*].FoundationId` | Custom: Owner-hez tartozik | "Az adott alapítvány nem ehhez az Owner-hez tartozik." |
