## Scope

Az `/owner/users` lista oldal és a meghívási dialog dinamikus Foundation-hozzárendelés hozzáadásával. Meglévő felhasználók Foundation-hozzárendelésének kezelése szintén itt.

---

## Acceptance Criteria

- [ ] **AC1**: A `/owner/users` oldalon megjelenik a „Új felhasználó meghívása" funkció és a felhasználói lista (oszlopok: név, email, alapítvány-hozzárendelések chips-szel, státusz).
- [ ] **AC2**: A meghívó form mezői: e-mail cím (`required, email`); dinamikus alapítvány + szerepkör hozzárendelések listája (`FormArray`, legalább egy elemmel — a min 1 sor kényszerét a UI biztosítja). „+ Alapítvány hozzáadása" gomb új sort vesz fel.
- [ ] **AC3**: A meghívó típusa automatikusan `OWNER` (a UI badge-dzsel jelzi: „Hatókör: Owner — Béta Kft."); az alapítvány-szintű hozzárendelések a meghívó-payload `embeddedAssignments` részeként tárolódnak (lásd `domain-model.md` CR2.2.5 `Invitation.IssueOwner(...)` művelet) és az elfogadáskor érvényesülnek.
- [ ] **AC4**: Ha a megadott e-mail cím már egy másik Owner-hez tartozó aktív felhasználóhoz tartozik, a backend 409-et ad (NK-13); a UI email mező-szintű hibaüzenetet mutat: „Ez az e-mail cím egy másik szervezethez tartozik."
- [ ] **AC5**: Meglévő Owner-felhasználónál (`existingUser` lista-item) a UI „Új Foundation-hozzárendelés" gombbal **közvetlenül** ad új hozzárendelést meghívó nélkül (`POST /api/v1/owner/users/{id}/assignments` az `appUserId` + `foundationId` + `role` payload-dal). Snackbar visszajelzés: „Felhasználó {foundationName}-hez {role} szerepkörrel hozzárendelve. (FoundationAssignmentCreated audit)".
- [ ] **AC6**: Egy felhasználó alapítvány-szintű hozzárendelése visszavonható (lista-soron a kuka ikon → megerősítő dialog: „Biztosan visszavonod {user.name} hozzárendelését a {foundation.name}-hoz?"). Az utolsó FoundationAdmin szabály érvényesül: ha az adott felhasználó az adott alapítvány utolsó aktív FoundationAdmin-ja, a visszavonó gomb disabled, tooltipje: „Az utolsó FoundationAdmin szerepköre nem vonható vissza." (lásd US-212 AC4, kompatibilitás).

- [ ] Route: `owner/users`

### Reactive Form (Owner Invite Dialog)
- [ ] `email`: `[required, email]`
- [ ] `foundationAssignments`: `FormArray`, min 1 elem; minden elem: `foundationId [required]`, `role [required]`
- [ ] „+ Hozzáad" → `FormArray.push()` új csoport

- [ ] Sikeres meghívás → snackbar + lista frissítés

## API Consumed

|---|---|---|---|

## UX / Behaviour

| Scenario | Expected behaviour |
|---|---|
| Egy Foundation-hozzárendelés-sor | Törlés gomb disabled (min 1 sor kötelező) |
| Sikeres meghívás | Snackbar + lista frissítés |
| 409 (NK-13 sérülés) | Email mező-szintű hiba: „Ez az e-mail más Owner-hez tartozik." |
| Közvetlen hozzárendelés meglévő userhez | Snackbar + lista frissül az új Foundation-nal |
