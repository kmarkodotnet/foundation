## Scope

Az `/owner/users` lista oldal és a meghívási dialog dinamikus Foundation-hozzárendelés hozzáadásával. Meglévő felhasználók Foundation-hozzárendelésének kezelése szintén itt.

### Feature Module (`src/app/features/owner/users/`)
- [ ] `owner-users-list.component.ts` + `.html` — felhasználó lista Foundation-oszlopokkal
- [ ] `owner-invite-dialog.component.ts` + `.html`:

## API Consumed

| Method | URL | Body | Response |
|---|---|---|---|

| `POST` | `/api/v1/owner/users/:id/assignments` | `{ foundationId, role }` | `200` |
| `DELETE` | `/api/v1/owner/users/:id/assignments/:foundationId` | — | `200` |
