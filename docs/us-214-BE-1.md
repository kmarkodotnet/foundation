## Scope

`OwnerCodeListTemplate` CRUD (meglévő `CodeList` infrastruktúra Owner-scope-ra adaptálva), újra-alkalmazás meglévő Foundation-ra (hiányzó tételek pótlása). Kizárólag Owner-scope-ban érhető el.

---

## Implementation Checklist

### Domain Layer
- [ ] `OwnerCodeListTemplate` aggregátum implementáció (lásd `domain-model.md` CR2.2.4):
  - `Create(ownerId, name)`, `AddItem(code, label)`, `UpdateItem(id, ...)`, `DeactivateItem(id)`
  - `ApplyToNewFoundation(foundationId)` — Foundation létrehozáskor automatikus snapshot-másolás
  - `ApplyToExistingFoundation(foundationId)` — **merge művelet (AC3 / US AC4)**: csak hiányzó tételek (azonos `Code` alapján) hozzáadása az adott Foundation `CodeList`-jéhez; **meglévő tételeket nem írja felül**, nem deaktivál.
  - Domain események: `OwnerCodeListTemplateCreated`, `OwnerCodeListTemplateUpdated`, `CodeListTemplateApplied`

### Application Layer (`GrantManagement.Application`)
- [ ] `GetOwnerCodeListTemplatesQuery` + Handler: Owner-szintű sablon lista
- [ ] `GetOwnerCodeListTemplateDetailsQuery` + Handler: sablon tételei
- [ ] `AddTemplateItemCommand` + Handler: új tétel a sablonba (`OwnerCodeListTemplate.AddItem(...)`)
- [ ] `UpdateTemplateItemCommand` + Handler: tétel módosítása (`UpdateItem(...)`)
- [ ] `DeleteTemplateItemCommand` + Handler: tétel deaktiválása (`DeactivateItem(...)`)
- [ ] `ApplyTemplateToFoundationCommand` + Handler:
  - Bemenetek: `TemplateId`, `TargetFoundationId`
  - Validálás: a `TargetFoundationId` ugyanazon Owner-hez tartozik (`Foundation.OwnerId == _scope.OwnerId`)
  - Hívás: `template.ApplyToExistingFoundation(targetFoundationId)` (lásd `domain-model.md` CR2.2.4)
  - Domain event `CodeListTemplateApplied` automatikusan kiváltja a `CODE_LIST_TEMPLATE_APPLIED` audit-bejegyzést (lásd us-233-BE-1) `details = { templateId, targetFoundationId, addedItems: [...] }`
- [ ] **Audit minden módosító műveletre (AC4)** — automatikus a domain event handler-eken keresztül:
  - `AddTemplateItemCommand` → `OWNER_CODE_LIST_TEMPLATE_UPDATED` audit
  - `UpdateTemplateItemCommand` → `OWNER_CODE_LIST_TEMPLATE_UPDATED` audit
  - `DeleteTemplateItemCommand` → `OWNER_CODE_LIST_TEMPLATE_UPDATED` audit
  - `ApplyTemplateToFoundationCommand` → `CODE_LIST_TEMPLATE_APPLIED` audit
- [ ] `OwnerCodeListTemplateListItemResponse`, `OwnerCodeListTemplateDetailsResponse` DTO-k

### API Layer (`GrantManagement.API`)
- [ ] `OwnerCodeListTemplatesController`: `API/Controllers/Owner/OwnerCodeListTemplatesController.cs`
  - `GET /api/v1/owner/code-list-templates` — `[Authorize(Policy = "CanReadOwner")]`
  - `GET /api/v1/owner/code-list-templates/{id}` — `[Authorize(Policy = "CanReadOwner")]`
  - `POST /api/v1/owner/code-list-templates/{id}/items` — `[Authorize(Policy = "IsOwnerAdmin")]`

  - `POST /api/v1/owner/code-list-templates/{id}/apply-to-foundation` — `[Authorize(Policy = "IsOwnerAdmin")]`

## API Contract

### POST /api/v1/owner/code-list-templates/{id}/apply-to-foundation
**Auth:** `IsOwnerAdmin`

**Request:**
```json
{ "targetFoundationId": "..." }
```

**200:** `{ "addedItemsCount": 5 }`  
**400** — Foundation más Owner-hez tartozik  
**404** — Sablon vagy Foundation nem létezik
