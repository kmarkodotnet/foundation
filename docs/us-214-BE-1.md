## Scope

`OwnerCodeListTemplate` CRUD (meglévő `CodeList` infrastruktúra Owner-scope-ra adaptálva), újra-alkalmazás meglévő Foundation-ra (hiányzó tételek pótlása). Kizárólag Owner-scope-ban érhető el.

## API Contract

### POST /api/v1/owner/code-list-templates/{id}/apply-to-foundation
**Auth:** `IsOwnerAdmin`

**Request:**
```json
{ "targetFoundationId": "..." }
```

**200:** `{ "addedItemsCount": 5 }`  
**400** — Foundation más Owner-hez tartozik  
**404** — Sablon vagy Foundation nem létezik
