## Scope

Owner-szintű összesítő dashboard lekérdezés: alapítványonkénti és aggregált pályázati statisztikák. Owner-audience JWT-vel érhető el; query filterek Owner-szintű kontextusban (FoundationId == null) futnak, így cross-foundation adatok lekérdezhetők.
