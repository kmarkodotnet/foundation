## API Contract

### GET /api/v1/owner/audit-logs

| Query param | Leírás |
|---|---|
| `foundationId` | Foundation szűrő (optional) |
| `userId` | Felhasználó szűrő |
| `startDate`, `endDate` | Dátum intervallum |
| `action` | pl. SCOPE_SWITCH, BREAK_GLASS_ACCESS |
| `page`, `pageSize` | Lapozás |

**Response:** azonos struktúra mint a meglévő audit log; `BREAK_GLASS_ACCESS` sorok `isBreakGlass: true` flag-gel kiemelve.

### GET /api/v1/owner/audit-logs/export
**Response:** `text/csv` stream, Content-Disposition: `attachment; filename="audit-{date}.csv"`
