## API Contract

### POST /api/v1/me/scope-switch
**Auth:** `[Authorize]` (bármely audience)

**Request:**
```json
{ "targetFoundationId": "..." }
```

Vagy Owner-szintű visszaváltáshoz:
```json
{ "targetFoundationId": null }
```

**Response 200:**
```json
{
  "accessToken": "eyJhbGci...",
  "expiresIn": 28800,
  "audience": "business",
  "foundationId": "...",
  "foundationName": "Béta Alapítvány"
}
```

**400** — `targetFoundationId` hiányos  
**403** — Foundation nem elérhető a felhasználó számára  
**422** — Foundation ARCHIVED állapotban
