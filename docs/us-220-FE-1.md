## Story

> As a **multi-foundation user**, I want to switch foundations with a single click in the UI, so that I don't need to log out and log back in.

---

## Scope

A navigációs sávban a Foundation-választó dropdown implementálása. Scope-váltáskor az új JWT tárolódik, a UI újratöltődik az adott Foundation kontextusában. OwnerAdmin számára „Owner áttekintés" opció is megjelenik.

---

## Implementation Checklist

### Core / Auth (`src/app/core/auth/`)
- [ ] `ScopeService`: `switchFoundation(targetFoundationId: string | null): Observable<void>`
  - POST `/api/v1/me/scope-switch`
  - Válasz `accessToken`-t eltárolja (localStorage kulcs: `access_token`)
  - Sikeres váltás után `window.location.reload()` vagy Angular `Router.navigate` + state invalidálás
- [ ] `ScopeService.getAvailableScopes(): Observable<AvailableScopesResponse>`
- [ ] `AuthService` frissítése: `currentFoundationId$` és `currentFoundationName$` signal/observable a JWT decode alapján

### Shared Component (`src/app/shared/components/foundation-switcher/`)
- [ ] `FoundationSwitcherComponent`:
  - `@Input() foundationId: string | null`
  - `@Input() foundationName: string | null`
  - **`@Input() foundationLogoUri: string | null`** (AC4 — `Foundation.LogoUri` mező a JWT-claim `available-scopes` válaszból)
  - `@Input() ownerName: string | null` és `@Input() ownerRole: 'OwnerAdmin' | 'OwnerAuditor' | null` az „Owner áttekintés" megjelenítéshez
  - Megjelenik, ha a felhasználónak > 1 Foundation-ja van **vagy** OwnerRole-ja van (AC1)
  - MatSelect dropdown az összes elérhető Foundation-lal:
    - **AC6** — Ha a felhasználó OwnerAdmin/OwnerAuditor: a dropdown **tetején** egy elválasztott szekcióban: `🏢 Owner áttekintés — {ownerName}` opció (értéke `null` → Owner-szintű scope-switch → `/owner/dashboard` redirect)
    - Foundation-szekció: minden elérhető Foundation neve + miniatűr logó (16×16 px) a sorban
  - Aktuális kiválasztott opció badge-ben: 24×24 px logó + Foundation név (AC4); ha nincs logó, default ikon (`<mat-icon>business</mat-icon>`)
  - Váltáskor spinner overlay az oldalon
- [ ] `AppLayoutComponent` bővítése: `<app-foundation-switcher [foundationLogoUri]="currentScope().foundationLogoUri" ...>` a navigációs sávban

### State / Data Flow
- [ ] `available-scopes` on-init betöltve (cacheelve az életciklus idejére)
- [ ] Scope-váltás közben: loader overlay → sikeres váltás → oldal kontextus frissítés (lista, dashboard újratöltése)
- [ ] Modal-ok bezárása scope-váltáskor (ha nyitva volt)
- [ ] Hiba esetén: toast „Sikertelen scope-váltás" + rollback

## UX / Behaviour

| Scenario | Expected behaviour |
|---|---|
| Egy Foundation-a van a usernek | Switcher nem jelenik meg (vagy csak a Foundation neve látszik) |
| Scope-váltás közben | Spinner overlay, gombok letiltva |
| OwnerAdmin | Dropdown tetején „Owner áttekintés" → Owner UI-ra navigál |
| Hiba (403) | Toast hibaüzenet, dropdown visszaáll az előző értékre |
