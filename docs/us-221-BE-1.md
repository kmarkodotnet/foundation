## Story

> As a **rendszer**, I want the invitation process to clearly handle invitation scope (Platform/Owner/Foundation), so that a user's roles across multiple levels don't get mixed up.

---

## Scope

A meglévő `Invitation` aggregátum bővítése `Scope`, `OwnerId`, `FoundationId` mezőkkel. Az `AcceptInvitationCommandHandler` bővítése scope-specifikus `AppUser` mutációkkal. Validáció: e-mail per scope egyedi PENDING meghívó (AC4), NK-13 (egy AppUser egy Owner) és szerepkör-keveredés tiltás.

---

## Implementation Checklist

### Domain Layer (`GrantManagement.Domain`)
- [ ] `Invitation` entitás bővítése:
  - `Scope: AssignmentScope` (`Platform | Owner | Foundation`)
  - `OwnerId: Guid?`
  - `FoundationId: Guid?`
  - `PlatformRole: PlatformRole?`
  - `OwnerRole: OwnerRole?`
  - `FoundationRole: FoundationRole?`

### Application Layer (`GrantManagement.Application`)
- [ ] `CreateInvitationCommand` bővítése: `Scope`, `OwnerId?`, `FoundationId?`, `PlatformRole?`, `OwnerRole?`, `FoundationRole?`
- [ ] `CreateInvitationCommandHandler` frissítése:
  - Validálja ki küldhet adott scope-ú meghívót: Platform → PlatformAdmin; Owner → PlatformAdmin; Foundation → OwnerAdmin VAGY FoundationAdmin
  - AC4: nincs más PENDING meghívó ugyanarra az email + scope kombinációra
  - NK-13: Foundation-scope meghívónál, ha az email már egy Owner-hez tartozó AppUser-é, csak ugyanahhoz az Owner-hez szóló meghívó fogadható el → validálja és dobja ha eltér
- [ ] `AcceptInvitationCommandHandler` bővítése scope ágakkal:
  - `Scope == PLATFORM`: `AppUser.AssignPlatformRole(invitation.PlatformRole!.Value)`
  - `Scope == OWNER`: `AppUser.AssignOwnerRole(invitation.OwnerId!.Value, invitation.OwnerRole!.Value)`, `AppUser.OwnerId = invitation.OwnerId`
  - `Scope == FOUNDATION`: `AppUser.AssignToFoundation(invitation.FoundationId!.Value, invitation.FoundationRole!.Value, invitedBy)`, `AppUser.OwnerId = foundation.OwnerId` (ha még nem volt)
  - NK-13 cross-Owner ellenőrzés elfogadáskor: ha `AppUser.OwnerId != null && AppUser.OwnerId != invitation.OwnerId` → `ForbiddenException("Ez a meghívó más szervezethez szól.")`

### Infrastructure Layer (`GrantManagement.Infrastructure`)
- [ ] `InvitationConfiguration` frissítése: `Scope`, `OwnerId`, `FoundationId`, `PlatformRole`, `OwnerRole`, `FoundationRole` új oszlopok
- [ ] Migráció: `dotnet ef migrations add CR2_ExtendInvitations`
