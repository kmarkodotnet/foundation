## Scope

A meghívó elfogadási oldalon és a meghívó-kiküldő dialógusokban a hatókör és szerepkör egyértelmű megjelenítése. Az elfogadási flow scope-specifikus visszajelzést ad.

---

## Implementation Checklist

### Meghívó elfogadási oldal (`src/app/features/auth/accept-invitation/`)
- [ ] `accept-invitation.component.ts` bővítése:
  - A meghívó payload-jából kiolvassa a Scope, OwnerId/FoundationId, Role mezőket
  - Olvasható leírás megjelenítése: „Ez a meghívó **FoundationAdmin** szerepkörre szól a **Z alapítványban**." (Foundation-scope)
  - Vagy: „Ez a meghívó **OwnerAdmin** szerepkörre szól a **Béta Alapítványkezelő Kft.**-nél." (Owner-scope)
  - Vagy: „Ez a meghívó **PlatformAuditor** szerepkörre szól a Platform adminisztrációhoz." (Platform-scope)
  - Google bejelentkezés + elfogadás gomb

### Meghívó lista (meglévő Admin/Owner meghívó kezelő)
- [ ] A meglévő meghívó-lista komponensben (`us-165-FE`) megjelenik a `Scope` és `Role` oszlop
- [ ] Szűrés `Scope` szerint (Platform / Owner / Foundation)

### Shared meghívó-dialog bővítések
- [ ] Platform invite dialog (us-203-FE-1-ben implementált): hatókör badge megjelenik a dialogon
- [ ] Owner invite dialog (us-213-FE-1-ben implementált): Foundation-hozzárendelések listája vizuálisan jelzi a hatóköröket

## API Consumed

A meglévő `GET /api/v1/invitations/{token}` endpoint visszaadja a Scope, Role, OwnerId/FoundationId mezőket (us-221-BE-1 scope-bővítés után).
