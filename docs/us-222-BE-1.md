## Story

> As a **rendszer**, I want to ensure that no API endpoint ever returns data belonging to a foreign scope, so that data leakage risk is effectively eliminated.

---

## Scope

Biztosítja, hogy az `AuthorizationBehaviour` scope-check, az EF query filterek és a `ScopeValidationMiddleware` összehangoltan és hiánytalanul lefedik az összes végpontot. Tartalmazza a whitelist-ellenőrzést és a SCOPE_VIOLATION auditálást. **Nem** ír új üzleti logikát — az összes védelmi réteg már megvalósult az us-231-BE-1 és us-223-BE-1-ben; itt az összehangolás, a teszt-lefedettség és a whitelist-mechanizmus kerül finalizálásra.

---

## Implementation Checklist

### Application Layer (`GrantManagement.Application`)
- [ ] Ellenőrzés: minden meglévő command/query handler, amelyik tenant-scope adathoz nyúl, implementálja `IScopedRequest`-et
- [ ] `AuthorizationBehaviour` véglegesítése: scope-check + locked-application check teljes, naplózott, `SCOPE_VIOLATION` audit ha eltérés
- [ ] `IgnoreQueryFilters` whitelist átvizsgálása: pontosan 3 callsite engedélyezett (platform audit, break-glass, expiration job); minden más callsite compiláció-szinten megtiltott a Roslyn analyzer-rel vagy architecture teszttel

### Infrastructure Layer (`GrantManagement.Infrastructure`)
- [ ] `ScopeValidationMiddleware` véglegesítése:
  - Ellenőrzi: `/api/v1/platform/*` → audience kell legyen `platform`
  - Ellenőrzi: `/api/v1/owner/*` → audience kell legyen `owner`
  - Business végponton Owner/Platform JWT → 403 (nem 401, mert authentikált, de rossz audience)
  - `SCOPE_VIOLATION` audit-esemény minden megsértésnél

### Architecture Tests (`GrantManagement.ArchitectureTests`)
- [ ] `AllTenantScopeEntitiesHaveQueryFilterTest` — reflection-nel végigmegy az összes `DbSet<T>` regisztráción; ahol `T` implementál `IOwnedEntity`-t (marker interface), ott kötelező `HasQueryFilter()` → CI elbukik, ha hiányzik
- [ ] `IgnoreQueryFiltersWhitelistTest` — Roslyn-alapú vagy reflection-alapú ellenőrzés: `IgnoreQueryFilters()` hívás csak `[ScopeBypassAllowed]` jelölt metódusban

## Required Tests

Tesztadatok:
- Owner A: Foundation X, Foundation Y
- Owner B: Foundation P, Foundation Q
- Mindegyik Foundation-ban: 1-1 Application, Granter, Vendor, CodeList rekord

Tesztek:
- [ ] Owner A JWT-vel összes üzleti endpoint lekérdezve → egyetlen Owner B rekord sem szerepel válaszban

- [ ] Owner B JWT-vel break-glass grant nélkül → Owner A adatai 403-mal elutasítva

- [ ] `GET /api/v1/owner/foundations` Platform JWT-vel → 401 (audience mismatch)
