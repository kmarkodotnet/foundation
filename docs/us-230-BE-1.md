## Story

> As a **rendszergazda**, I want to migrate existing single-tenant data to a multi-tenant model under a default Owner + Foundation, so that the system transitions to CR2 without data loss.

---

## Scope

Megvalósítja a teljes CR2 adatbázis-migrációt: új Tenancy táblák létrehozása, meglévő aggregátumok `OwnerId`/`FoundationId` bővítése, backfill SQL, `AppUser` szerepkör-migráció és fájlútvonal-frissítés. **Nem** tartalmazza a domain logikát vagy API-végpontokat — csak a séma- és adatmigrációt.

## Adatbázis-séma (új táblák)

```sql
-- Owners
CREATE TABLE "Owners" (
  "Id" uuid PRIMARY KEY,
  "Name" varchar(200) NOT NULL,
  "ContactEmail" varchar(320) NOT NULL,
  "Status" varchar(20) NOT NULL DEFAULT 'Active',
  "CreatedAt" timestamptz NOT NULL,
  "UpdatedAt" timestamptz NOT NULL
);

-- Foundations
CREATE TABLE "Foundations" (
  "Id" uuid PRIMARY KEY,
  "OwnerId" uuid NOT NULL REFERENCES "Owners"("Id"),
  "Name" varchar(200) NOT NULL,
  "LogoUri" varchar(500),
  "Status" varchar(20) NOT NULL DEFAULT 'Active',
  "CreatedAt" timestamptz NOT NULL,
  "UpdatedAt" timestamptz NOT NULL
);

-- FoundationUserAssignments
CREATE TABLE "FoundationUserAssignments" (
  "Id" uuid PRIMARY KEY,
  "AppUserId" uuid NOT NULL REFERENCES "AppUsers"("Id"),
  "FoundationId" uuid NOT NULL REFERENCES "Foundations"("Id"),
  "FoundationRole" varchar(30) NOT NULL,
  "AssignedAt" timestamptz NOT NULL,
  "AssignedByUserId" uuid NOT NULL,
  "IsActive" boolean NOT NULL DEFAULT true,
  UNIQUE ("AppUserId", "FoundationId") WHERE "IsActive" = true
);

-- BreakGlassGrants
CREATE TABLE "BreakGlassGrants" (
  "Id" uuid PRIMARY KEY,
  "PlatformAdminUserId" uuid NOT NULL,
  "TargetOwnerId" uuid NOT NULL REFERENCES "Owners"("Id"),
  "Reason" varchar(2000) NOT NULL,
  "IssuedAt" timestamptz NOT NULL,
  "ExpiresAt" timestamptz NOT NULL,
  "Status" varchar(20) NOT NULL DEFAULT 'Active',
  "RevokedAt" timestamptz
);
CREATE INDEX "IX_BreakGlassGrants_Status_ExpiresAt" ON "BreakGlassGrants" ("Status", "ExpiresAt");
```

## Migrációs sorrend és idempotencia

A migráció háromfázisú és idempotens:

```csharp
// Migráció 2 idempotencia mintája:
IF NOT EXISTS (SELECT 1 FROM "Owners" WHERE "Name" = 'Default Owner')
BEGIN
  INSERT INTO "Owners" ...
END
UPDATE "Applications" SET "OwnerId" = @defOwner, "FoundationId" = @defFound
WHERE "OwnerId" IS NULL OR "FoundationId" IS NULL;
```

A migráció **egyirányú** — rollback szándékosan nem támogatott (AC9); a `Down()` metódus `throw new NotSupportedException("CR2 migration is one-way")`.
