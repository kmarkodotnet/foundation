## Story

> As a **rendszer**, I want every tenant-scoped EF Core entity to have a mandatory global query filter on OwnerId and FoundationId, so that the database layer is the final safeguard against data leakage.

---

## Scope

Bevezeti a teljes EF Core global query filter réteget: `AppDbContext` bővítése, `ICurrentScopeService` injektálás, `SaveChangesAsync` scope-injection, `IgnoreQueryFilters` whitelist és a `ScopeValidationMiddleware`. Nem tartalmaz üzleti logikát vagy API-végpontokat.

---

## Implementation Checklist

### Infrastructure Layer (`GrantManagement.Infrastructure`)
- [ ] `AppDbContext` konstruktor bővítése: `ICurrentScopeService _scope` injektálva (nem `IHttpContextAccessor` közvetlenül — a scope szolgáltatás absztrahálja)
- [ ] `OnModelCreating()` filter minden tenant-scope entitásra (Application, Granter, Vendor, CodeList, Notification, Document, Comment):

```csharp
modelBuilder.Entity<Application>().HasQueryFilter(a =>
    !a.IsArchived
    && a.OwnerId == _scope.OwnerId
    && (_scope.FoundationId == null || a.FoundationId == _scope.FoundationId));

// Notification, Document, Comment, Granter, Vendor, CodeList — azonos minta, !IsArchived / !IsDeleted
```

- [ ] Owner-szintű kontextus (`FoundationId == null`): a filter csak `OwnerId` szerint szűr — cross-foundation aggregátum-lekérdezések engedélyezve Owner audience-nél
- [ ] Platform-szintű kontextus: a Tenancy entitások (Owners, Foundations, BreakGlassGrants) **nem** kapnak tenant query filtert; minden business entitás `OwnerId == null`-ra szűr (elvileg soha nem teljesül normál querycre, csak IgnoreQueryFilters-szel)
- [ ] `SaveChangesAsync` override bővítése: új `BaseEntity` példányokon automatikusan beállítja `OwnerId = _scope.OwnerId`, `FoundationId = _scope.FoundationId` ha nincsenek explicit beállítva; inkonzisztencia esetén `InvalidOperationException`
- [ ] `IgnoreQueryFilters()` whitelist — `ScopeBypassAllowedAttribute`:

```csharp
[AttributeUsage(AttributeTargets.Method)]
public sealed class ScopeBypassAllowedAttribute : Attribute
{
    public string Reason { get; }
    public ScopeBypassAllowedAttribute(string reason) => Reason = reason;
}
```

Három engedélyezett callsite:
  1. `PlatformAuditLogQueryHandler` — platform-szintű lekérdezés
  2. `BreakGlassActiveAccessHandler` — érvényes grant + explicit OwnerId filter
  3. `BreakGlassExpirationJob` — background job, explicit Owner-kontextus váltással

- [ ] `BreakGlassExpirationJob`: `Infrastructure/BackgroundJobs/BreakGlassExpirationJob.cs` (Hangfire recurring, óránként)
  - Minden `BreakGlassGrant`-on ahol `Status == Active && ExpiresAt < now`
  - Explicit `_scope.SwitchTo(grant.TargetOwnerId)` minden iteráció előtt
  - Status → `EXPIRED`, audit-bejegyzés `BREAK_GLASS_EXPIRED`
  - `[ScopeBypassAllowed("Background job — processes all owners explicitly")]` annotáció az EF lekérdezésen

- [ ] `ScopeValidationMiddleware`: `API/Middleware/ScopeValidationMiddleware.cs`
  - Minden kérésen: ellenőrzi, hogy az `ICurrentScopeService` scope betöltött
  - Ha az audience és az endpoint prefix nem egyezik (pl. `business` JWT-vel `/api/v1/platform/` prefix) → 401 még controller előtt

### Application Layer (`GrantManagement.Application`)
- [ ] `AuthorizationBehaviour` bővítése scope-check-kel: `IScopedRequest` interfész implementációkat ellenőrzi `_currentScopeService`-en keresztül, eltérés → `ForbiddenException("Scope mismatch")`
- [ ] `IScopedRequest` interfész: `Application/Common/Interfaces/IScopedRequest.cs`

```csharp
public interface IScopedRequest
{
    ScopeRequirement GetScopeRequirement();
}

public record ScopeRequirement(Guid? OwnerId, Guid? FoundationId, string RequiredAudience);
```

## Notes

- Az `AppDbContext` konstruktor bővítése **breaking change** a meglévő tesztekben — minden `AppDbContext` tesztinicializálást frissíteni kell mock `ICurrentScopeService`-szel.
- A `ICurrentScopeService` Scoped élettartamú; a `AppDbContext` szintén Scoped → az injektálás DI-szempontból helyes.
- A `BreakGlassExpirationJob` Transient élettartamú Hangfire context-ben; szükséges `IServiceScopeFactory` használata az injektáláshoz.
