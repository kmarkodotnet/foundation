## Story

> As a **fejlesztő**, I want CI-level regression tests to guarantee cross-tenant isolation, so that a careless commit cannot introduce data leakage.

---

## Scope

A teljes CR2 teszt-suite megvalósítása: architecture tesztek (NetArchTest/reflection alapú), cross-tenant integrációs regresszió-tesztek (Testcontainers), break-glass workflow integráció-teszt és scope-switch izolációs teszt. Ez a task **kizárólag tesztkódot** ír.

---

## Implementation Checklist

### Architecture Tests projekt (`GrantManagement.ArchitectureTests`)
- [ ] `QueryFilterCoverageTest`: minden `IOwnedEntity` implementáló entitás-típushoz van `HasQueryFilter()` hívás az `AppDbContext.OnModelCreating()`-ben

```csharp
[Fact]
public void All_owned_entities_must_have_query_filter()
{
    var ownedEntityTypes = Assembly.GetAssembly(typeof(Application))!
        .GetTypes()
        .Where(t => typeof(IOwnedEntity).IsAssignableFrom(t) && !t.IsInterface)
        .ToList();

    var dbContextSource = File.ReadAllText("path/to/AppDbContext.cs");

    foreach (var entityType in ownedEntityTypes)
    {
        Assert.Contains($"HasQueryFilter", dbContextSource); // simplified; real check uses reflection on model
    }
}
```

- [ ] `IgnoreQueryFiltersWhitelistTest`: `IgnoreQueryFilters()` hívások a solution-ben kizárólag `[ScopeBypassAllowed]` annotált metódusokban lehetnek; Roslyn-alapú vagy reflection + ILSpy-alapú ellenőrzés
- [ ] `DependencyDirectionTest`: Domain nem hivatkozik Infrastructure-ra; Application nem hivatkozik API-ra (meglévő teszt frissítése CR2 névterekkel)
- [ ] `NamingConventionTest`: minden `IScopedRequest` implementáló command/query class nevére illeszkedik a regex `.*Command|.*Query`

### Integration Tests projekt (`GrantManagement.IntegrationTests`)

**Teszt fixture: `CrossTenantIsolationFixture`**

```csharp
// Setup: két Owner (A, B), mindegyiknek két Foundation (X/Y, P/Q)
// Minden Foundation-ban: 1 Application, 1 Granter, 1 Vendor rekord
// AppUser U1 → Owner A, Foundation X, FoundationAdmin
// AppUser U2 → Owner B, Foundation P, FoundationAdmin
```

- [ ] `CrossTenantIsolationTests`
  - `GET /api/v1/applications` Owner A JWT → csak Owner A Application-ök (0 Owner B rekord)
  - `GET /api/v1/granters` Owner A JWT → csak Owner A Granter-ek
  - `GET /api/v1/applications` Foundation X JWT → csak Foundation X Application-ök (Foundation Y sem látszik)
  - `POST /api/v1/applications` Foundation X JWT-vel Application létrehozása → nem kerülhet Foundation Y-ba (OwnerId/FoundationId auto-inject)
  - `GET /api/v1/applications/{id}` ahol id Owner B-hoz tartozik, Owner A JWT-vel → 404 (nem 403 — scope filter miatt nem látszik)

- [ ] `BreakGlassWorkflowIntegrationTest`
  - PlatformAdmin kiállít BreakGlassGrant Owner A-ra
  - Break-glass JWT-vel Owner A adata olvasható
  - `ExpiresAt` lejár → job futtatva → Grant Status = EXPIRED
  - Lejárt grant JWT-vel kérés → 403
  - Audit-bejegyzések: BREAK_GLASS_ACCESS, BREAK_GLASS_EXPIRED mind megvan

- [ ] `ScopeSwitchIsolationTest`
  - Felhasználó Foundation X-en → Foundation X adatai
  - Scope switch Foundation Y-ra → Foundation Y adatai látszanak, X-é nem
  - `GET /api/v1/me/available-scopes` → csak saját Foundationok

- [ ] `ScopeClaimManipulationSecurityTest`
  - Módosított JWT (kézzel megváltoztatott `owner_id` claim) → 401 (invalid signature)
  - Érvényes `business` audience JWT-vel `GET /api/v1/platform/owners` → 401 (audience mismatch)
  - Érvényes `owner` audience JWT-vel `GET /api/v1/applications` → 401 (audience mismatch)
